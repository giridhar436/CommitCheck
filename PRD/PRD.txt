CommitCheck
Hackathon: Hackloop Season 5
Track: Generative AI
Product Type: AI-powered B2B Web Application
Primary Users: Freelancers, software agencies, project managers, small software teams
1. Product Overview
CommitCheck is an AI-powered web application that helps software agencies and freelancers prevent unauthorized scope creep.
After a client meeting, the user provides the meeting summary, notes, transcript, screenshot, or document to CommitCheck. The system identifies requirements and commitments made during the meeting and compares them with the project's approved scope.
If the system detects that someone has promised work that was not part of the approved scope and has no recorded approval, it alerts the team and can create a structured change request before the work begins.
Core idea
Make sure what was promised to the client is actually approved before it becomes work.

2. Problem Statement
Software agencies and freelancers frequently discuss project requirements and changes during client meetings.
A client might say:
"Can we also add Google Login?"

And a developer might respond:
"Sure, I'll add it by Friday."

The problem is that this commitment may never be formally added to the project's approved scope.
This can lead to:
- Scope creep
- Unpaid work
- Lost development time
- Missed deadlines
- Reduced project profitability
- Misunderstandings between clients and teams
- Disputes about what was actually agreed
Existing project-management tools generally manage work after it becomes a task.
CommitCheck focuses on the earlier stage:
Conversation → Commitment → Authorization → Work

3. Product Vision
CommitCheck aims to become an AI-powered verification layer between client communication and project execution.
Its purpose is to ensure that commitments made during client interactions are checked against the project's approved scope before they become actual development work.
4. Target Users
4.1 Freelancers
A freelancer may accidentally agree to additional work during a client meeting.
CommitCheck helps them identify:
"Did I just promise something that wasn't part of the original agreement?"

4.2 Software Agencies
Agencies often have multiple developers and project managers communicating with clients.
CommitCheck helps owners identify:
- Unauthorized commitments
- Scope changes
- Potential revenue leakage
- Unapproved work
4.3 Project Managers
Project managers can use CommitCheck to review meeting outcomes and determine:
- What changed?
- What was promised?
- Was it already approved?
- Does a change request need to be created?

22. Risk Classification
CommitCheck should not treat every AI detection as absolute truth.
Instead, it provides a risk level.
Risk	Meaning
🟢 Low	Commitment appears authorized or within scope
🟡 Medium	Ambiguous commitment or authorization
🔴 High	Clear commitment outside scope with no approval


The user can inspect the evidence before taking action.

37. Privacy & Security
Because the application processes potentially sensitive client information, privacy is a major product requirement.
Principles
- User-authorized input only
- No continuous meeting monitoring in the MVP
- Organization-level data isolation
- Role-based access
- Secure authentication
- HTTPS
- Secure file storage
- Controlled access to uploaded documents
- Data deletion capability
- Audit logging
- Minimum necessary data access
User consent
The user explicitly chooses to provide meeting information for analysis.
The MVP does not secretly monitor or record meetings.
38. What We Are NOT Building
This distinction is important.
CommitCheck is not:
❌ A replacement for Google Meet
❌ A replacement for Jira
❌ A replacement for Slack
❌ A project-management platform
❌ A meeting recording platform
❌ A continuous surveillance system
❌ A legal decision-making system
Instead:
CommitCheck is a verification layer between client communication and project execution.

42. Product Differentiator
CommitCheck is not another task-management application.
The key difference is when it intervenes.
Traditional workflow:
Conversation → Someone promises work → Task gets created → Team builds it

CommitCheck:
Conversation → Commitment detected → Scope checked → Authorization verified → Work

Therefore, the product addresses the moment when scope creep begins, rather than only managing the work afterward.

45. Final Product Definition
CommitCheck is an AI-powered web application that analyzes user-authorized client meeting summaries to identify requirements and commitments, compares them with the approved project scope, and detects potential unauthorized scope changes. When an unauthorized commitment is found, CommitCheck explains the evidence, alerts the project team, and generates a structured change request for approval before the work begins.
