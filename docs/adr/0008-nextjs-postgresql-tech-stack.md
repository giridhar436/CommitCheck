# 0008: Next.js App Router and PostgreSQL Tech Stack

We decided on Next.js (App Router, TypeScript) paired with PostgreSQL (via Prisma ORM / Supabase) and Tailwind CSS with shadcn/ui. This provides a unified TypeScript stack spanning frontend client dashboards, server-side data fetching, OAuth handlers, secure server actions, and API webhooks for third-party integrations (Recall.ai and Resend).
