# Full-Stack AI SaaS Architecture Resources

## Knowledge

- [Next.js Official Documentation (App Router)](https://nextjs.org/docs)
  Comprehensive guide to Server Components, routing, layouts, and data fetching. Use for: understanding Next.js request lifecycles and component boundaries.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
  Authoritative reference for static typing in JavaScript. Use for: typing interfaces, generics, function signatures, and union types.
- [React 19 Official Documentation](https://react.dev)
  Modern React mental model covering JSX, hooks, state, and unidirectional data flow. Use for: understanding client UI reactivity.
- [Prisma ORM Documentation](https://www.prisma.io/docs)
  Next-generation Node.js and TypeScript ORM guide. Use for: schema modeling, relational migrations, and type-safe database queries.
- [Google Gen AI SDK Docs](https://ai.google.dev/gemini-api/docs)
  Primary guide for Gemini multimodal and structured JSON output generation. Use for: integrating LLM verification and structured data extraction.
- [Recall.ai Documentation](https://docs.recall.ai)
  Universal meeting bot API. Use for: understanding bot dispatch, lifecycle webhooks, and speaker-diarized transcripts.

## Wisdom (Communities)

- [Next.js Official Discord](https://discord.gg/nextjs)
  Active community of full-stack Next.js builders. Use for: debugging modern App Router patterns and deployment questions.
- [TypeScript Community Discord](https://discord.gg/typescript)
  Specialized server for typing puzzles and compiler best practices. Use for: advice on tricky generics or type narrowing.
- [Prisma Community Slack & Discord](https://www.prisma.io/community)
  High-signal community for database schema design and relational query optimization. Use for: schema critiques and migration strategies.
