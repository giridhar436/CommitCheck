# Mission: Full-Stack AI SaaS Architecture (via CommitCheck)

## Why
The user wants to progress from foundational JavaScript to independently designing and shipping production-ready, AI-integrated full-stack SaaS applications. Mastering the architecture in CommitCheck equips them to build scalable products combining typed frontends, secure dual-role OAuth, relational database modeling, external webhook pipelines, and structured LLM verification.

## Success looks like
- Write and navigate TypeScript code confidently across client and server boundaries in Next.js.
- Explain and implement Next.js App Router patterns (Server Components, Client Components, Route Handlers).
- Model relational data schemas and handle persistence using Prisma ORM and PostgreSQL.
- Architect secure OAuth 2.0 authentication flows tailored for multi-stakeholder roles (e.g., GitHub for developers, Google for clients).
- Ingest asynchronous third-party webhooks safely (e.g., meeting transcription bots via Recall.ai).
- Integrate Google Gemini 1.5 Pro with structured JSON schema outputs to automate business logic.

## Constraints
- Baseline: Plain JavaScript familiarity; no assumed prior knowledge of TypeScript types, JSX/React lifecycle, or SQL/ORM abstractions.
- Learning progression must bridge vanilla JS concepts step-by-step into modern framework paradigms.
- Lessons must be bite-sized, interactive, and visually refined.

## Out of scope
- Low-level audio/video codec encoding or real-time WebRTC media servers.
- Complex Kubernetes or multi-region infrastructure deployment.
- Native mobile development (iOS/Android).
